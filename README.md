Smart Invoice Generator
 
What is This Project?

This is a simple web application that helps you create professional invoices really quickly. Instead of making invoices in Word or Excel, you can just fill in some information on this website and download your invoice as a PDF file. It's super easy!

What Can You Do With It?

- **Add Your Business Info**: Put your company name, address, and contact details
- **Add Client Details**: Enter the client's name and their address
- **Add Items/Services**: Add multiple products or services with quantity and price
- **Set Taxes & Discounts**: Automatically calculate taxes and add discounts
- **Preview Invoice**: See how your invoice looks before downloading
- **Download as PDF**: Save your invoice as a PDF file and send it to your client

## How to Use It?

1. Open the "index.html" file in your web browser
2. On the left side, fill in all the details:
   - Your business information
   - Client information
   - Invoice number and dates
   - Add line items (what you're charging for)
   - Add any notes or payment terms
3. You'll see a live preview on the right side
4. When everything looks good, click the **"Download PDF"** button
5. Your invoice will be saved as a PDF file

 How to Run

Just open `index.html` in any web browser (Chrome, Firefox, Edge, etc.). That's it! No need to install anything or run special commands.

Example

Let's say you completed a design project for a client. You can:
1. Enter your company name
2. Enter the client's name
3. Add the service "Web Design" for $2500
4. Set the invoice date and due date
5. Click download and send the PDF to your client

Notes

- This project works completely offline (after loading)
- Your data is not saved anywhere - it's only in the browser
- Every time you refresh the page, it resets to the default values
- You can edit any field and see changes immediately in the preview
